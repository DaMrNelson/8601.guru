# ISO 8601 Helper
Displays info on [ISO 8601 durations](https://docs.digi.com/resources/documentation/digidocs/90001488-13/reference/r_iso_8601_duration_format.htm), like crontab.guru. Might support other parts of the 8601 spec later.

Driver for creating this was that I was writing ISO 8601 comments for Microsoft Logic Apps and wanted a quick way to check my formatting.
